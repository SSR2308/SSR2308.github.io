Chest X-Ray Classification (AI/ML)

Built a three-class chest X-ray classifier (Normal / Pneumonia / Tuberculosis) on ~30,000 images using a MobileNetV2 feature extractor feeding a hybrid classifier pipeline. After 300+ hyperparameter runs and augmentation to handle class imbalance, the model reached 78% overall accuracy — but the headline number hid a real problem: pneumonia recall was near-perfect while TB recall sat around 0.63, meaning the model could look accurate while still missing the cases that matter most clinically.

That reframed the project around failure modes instead of top-line accuracy: plotting per-class precision-recall curves, checking calibration so predicted probabilities are meaningful, and adjusting sensitivity specifically for TB detection. Submitted to AIRC 2026.
